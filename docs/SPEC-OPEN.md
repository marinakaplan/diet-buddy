## א. דורש פעולה של מרינה (לא ניתן לבצע מהקוד)

### 1. לבדוק התראה אמיתית בטלפון
- **מצב**: עד הביקורת ה-service worker לא נרשם בכלל בפרודקשן, ולכן שום טלפון לא יכול היה לקבל התראות (במסד: 0 מינויים). זה תוקן ונבדק בדפדפן אוטומטי, אבל שליחה אמיתית לטלפון אמיתי עוד לא אומתה.
- **מה לעשות אחרי הפריסה**: לפתוח `/fresh`, להוסיף את מילה למסך הבית (באייפון חובה), לפתוח משם, הגדרות ← ״התראות במכשיר הזה״ ← ״להפעיל״, ואז ״שליחת התראת בדיקה״.
- **אם לא מגיע**: לשלוח צילום של מה שכתוב שם. הסיבה הסבירה ביותר: שירות ההתראות של מוזילה/אפל חסום ברשת, או הרשאה שנדחתה בעבר.

### 2. להפוך את GOOGLE_CLIENT_SECRET לסוד
- **מצב**: ב-Worker ״mila״ הערך שמור כטקסט רגיל (מי שנכנסת ללוח הבקרה רואה אותו).
- **מה לעשות**: Cloudflare ← Workers ← mila ← Settings ← Variables ← לערוך את GOOGLE_CLIENT_SECRET ולסמן Encrypt/Secret.

### 3. פרטים בדפים המשפטיים
- **מצב**: המפעילה רשומה כ״מרינה, יוצרת האפליקציה״, והמייל `a.gen.c2026@gmail.com` (הנחתי `.com`; נכתב `.col`).
- **להחליט**: שם מלא או שם עסק? המייל נכון? מומלץ שעורכת דין תעבור על תנאי השימוש ומדיניות הפרטיות לפני הפצה רחבה.
