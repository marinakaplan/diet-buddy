## נתונים (לניתוח עתידי, בלי מסכי סטטיסטיקה)

- `word_definitions.library_id`, `category`, `library_version` — אתגר מהספרייה; אתגר אישי: `library_id = null` (לא מצטרף לספרייה הציבורית).
- `word_commitments.reward`, `reward_shared` — פרס אישי. נחשף לחברות רק אם `reward_shared = 1`.
- `circle_invites.kind`, `message`, `library_id`, `word_title` — סוג ההזמנה והנוסח.
- `social_events.type = 'overtake'`, `notifications.type = 'overtake'` — ״המהפך״.
- מהשדות האלה אפשר לחשב בעתיד: משתתפות לכל אתגר, אחוזי הצלחה, השלמת סבבים, נטישה, השוואות בין קטגוריות — רק במצטבר, ובלי קטגוריות רגישות.
