# מילון מילה — מונח אחד לכל דבר

כל מסך, הודעה, התראה ובדיקה משתמשים במונחים האלה בלבד. אין מונחים טכניים (הכרעה, זקיפה, סטטוס, יתרה כוללת) בממשק.

## המשחק במשפט אחד

> כל יום עד 3 שקלים על הכף. עמדת במילה? השקל שלך. פספסת? הוא עובר לקופה. הכי התמדת? את מובילה.

(אין ״זכייה בקופה״ בממשק: מנגנון חלוקת הקופה לא ממומש.)

## מונחי ליבה

| מושג | בממשק | הערות |
|---|---|---|
| התחייבות | **מילה** | לעולם לא ״אתגר״, ״התחייבות״, ״משימה״ |
| יצירת התחייבות | **לתת מילה** | כפתור ראשי בהיום ובמסך הפתיחה |
| אישור סופי (כל מקום) | **חותמת על זה** | פרופיל, אשף מילה, הצטרפות למילה של הקבוצה |
| רשימת ההתחייבויות שלי | **המילים שלי** | |
| מה צריך לעשות היום | **המילים שלי להיום** | כותרת הסקשן במסך היום, עם מונה `0/3` |
| סיום סבב | **המילה האחרונה** | מסך סיכום סבב |
| הצלחה יומית | **עמדתי במילה** / **אמרת ועשית** | כפתור / אישור וטוסט |
| פספוס | **פספסתי** / **לא היום** | כפתור / כותרת אישור |
| החרגה | **יום חריג** | ״לא נספר ולא שובר רצף. עד 2 בסבב.״ |
| תיקון דיווח | **טעות? לתקן** | עד 24 שעות |
| רצף 14 יום | **מילה בסלע** | הישג |
| עידוד | **מילה טובה** | גיליון עידוד + הישג |

## קבוצות

| מושג | בממשק |
|---|---|
| מעגל / קבוצה | **קבוצה** (״מעגל״ לא מופיע יותר) |
| רשימת הקבוצות | **הקבוצות שלי** |
| יצירת קבוצה | **קבוצה חדשה** → כפתור **פותחת ומזמינה** |
| הזמנה (כותרת + התראה) | **באה איתי?** |
| קבלת הזמנה / הצטרפות למילה | **אני בפנים** |
| הצעת מילה לקבוצה | **מילה לכולנו** → כפתור **חותמת ומזמינה** |
| המילה הקבוצתית | **המילה של כולנו** |
| מי עדיין לא הצטרפה | **מילים שמחכות לך** |
| דירוג | **מי מובילה?** |
| קופת הקבוצה | **בקופה** · ״שקלים שפוספסו בסבב״ |
| שיתוף קוד | **מי איתך?** · ״שלחי את הקוד לחברות שיעזרו לך לעמוד במילה.״ |

## שקלים

| מושג | בממשק |
|---|---|
| יתרה | **השקלים שלי** |
| מה שצברתי | **הרווחת** (בסבב / בסך הכול) |
| מה שהוחמץ בקבוצה | **הלך לקופה** |
| מה שעוד פתוח היום | **על הכף היום** |
| פספוס במילה פרטית | **לא היום** (אין קופה, השקל פשוט לא נוצר) |
| סכום בודד | **+1 ₪** / **−1 ₪** בצ׳יפ, אף פעם לא במשפט |

תמיד מוצג: על הכף היום · הרווחת בסבב · הלך לקופה · בקופה (בקבוצה) · המיקום שלי (מי מובילה?).

## ניווט

היום · קבוצות · אני

## כללי כתיבה

1. כותרת 2–4 מילים. בלי פסקאות הסבר במסכים הראשיים.
2. פעולה ראשית אחת בכל מסך.
3. כסף, דירוג ורצף מובנים בלי לקרוא: מספר + צבע + אייקון.
4. חשיפה הדרגתית: הסבר מלא רק ב״איך זה עובד״ (הגדרות) ובגיליונות.
5. לשון נקבה, ישירה, בלי ״בבקשה״ ובלי סימני קריאה.
