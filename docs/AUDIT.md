## 4. זרימות משתמש שנבדקו בדפדפן (לא רק בדיקות יחידה)

הרצה ב-Chromium (Playwright) על `mila/` בפורט מקומי:

| זרימה | תוצאה |
|---|---|
| פתיחה → דמו → היום → דיווח הצלחה → בנק מתעדכן | ✅ |
| אשף מילה 4 צעדים עם תקרה מלאה → הודעת תקרה + "להתחיל ב-16.11" | ✅ |
| מעגל → דירוג → עידוד | ✅ |
| מילה קבוצתית שחוסמת תקרה (מסע D) | ✅ כפתור מושבת, הסבר, "לא מוחקים התחייבות" |
| הזמנה → תצוגה מקדימה → הצטרפות | ✅ מקומי; ענן נבדק ברמת SQL בלבד עד שיהיה פרויקט Supabase |
| סיכום סבב → "עוד סיבוב?" פותח אשף ממולא | ✅ |
| תיקון דיווח בתוך 24 שעות | ✅ |
| **שתי משתמשות אמיתיות באותו מעגל (שלב 5)** | ◐ עבר ברמת השרת (`server_rules.sql`: הרשמה → מעגל → הזמנה → הצטרפות → מילה קבוצתית → אימוץ → דיווחים → בנק וקופה אצל שתיהן). הרצה מלאה בדפדפן ממתינה לפרויקט Supabase (ראו דוח) |
