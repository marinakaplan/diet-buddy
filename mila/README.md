# מילה. — המילה שלך שווה משהו

משחק חברתי של התחייבויות: נותנים ״מילה״ ל-14 יום, מדווחים כל יום, ושקל מילה וירטואלי אחד עומד על הכף.
עמדת במילה — השקל נשמר בבנק שלך. פספסת — השקל עובר לקופת המעגל. אין כסף אמיתי, אין רכישה, אין פדיון.

מימוש של מסמך האפיון ״מילה | אפיון מוצר מקצה לקצה, גרסה 1.0״, בסגנון העיצוב של המוקאפ (פסטל ורוד־אפרסק, כרטיסים לבנים מעוגלים, ליים כצבע פעולה).

## הרצה

אפליקציית PWA סטטית בעברית (RTL), ללא build step.

```bash
npm start          # http://localhost:3456  (npx serve)
# או
npm run dev        # python3 -m http.server 3456
npm test           # בדיקות מנוע (node)
```

במסך הפתיחה אפשר ללחוץ ״להציץ עם נתוני דוגמה״ כדי לטעון מעגלים, חברות ומילים לדוגמה. איפוס מההגדרות.

הזמנה למעגל: `/?invite=TOKEN` (הקוד מופיע בגיליון ״להזמין חברה״).

## חוקי המשחק שממומשים

- סבב של 14 ימים; מילה אישית או קבוצתית; לכל משתתפת במילה קבוצתית מופע התחייבות נפרד.
- לכל היותר 3 אירועים מחייבים ביום לכל משתמשת, בכל המעגלים יחד. נבדק ביצירה ובאימוץ, עם הצעת תאריך פנוי.
- חלון דיווח: מ-00:00 ביום עד 10:00 למחרת. יום שלא דווח נזקף כפספוס אוטומטית ("לא דווח"). תיקון אפשרי 24 שעות אחרי ההכרעה.
- הצלחה → `EARN`; פספוס → `MISS_TO_CIRCLE` / `MISS_PERSONAL`; החרגה (עד 2 בסבב) → ללא מטבע, לא שוברת רצף.
- תיקון = `REVERSE` + תנועה חדשה. אין מחיקה. כל מסך נגזר מהיומן.
- דיווח כפול מחזיר את ההכרעה הקיימת. אין יתרות שליליות, אין העברה, אין המרה.
- דירוג לפי שיעור הצלחה (`success / (success + miss)`), מינימום 3 הכרעות, שבירת שוויון לפי הצלחות ואז רצף, מקום משותף בשוויון מלא. אפשר להסתיר את עצמי.
- הצטרפות למעגל לא יוצרת התחייבות. עזיבה מסיימת מילים פעילות ושומרת היסטוריה. מנהלת שעוזבת מעבירה ניהול.
- בטיחות: חסימה, דיווח על משתמשת/מעגל/הזמנה, סינון ניסוחים מסוכנים, 18+.

## מה עדיין לא כאן

- שרת: המנוע רץ כרגע בדפדפן מעל `localStorage` (local-first). הוא כתוב כך שאפשר להעביר אותו אחד־לאחד לשרת מול `mila-schema.sql`; "חברות" בדמו מדומות במכשיר.
- התראות דחיפה אמיתיות (ההגדרות קיימות, הסטטוסים קיימים, השליחה לא).
- שכבת ההשפעה/תרומות (P2) — בכוונה לא קיימת במוצר, לפי האפיון.
